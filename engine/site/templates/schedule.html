이 {{ kw }}은 베트맨 프로토 승부식에 발매된 경기를 기준으로 매일 자동으로 갱신됩니다. 대상은 {{ sc.ex }} 등이고, 발매가 열리는 대로 앞으로 2~3일치가 올라옵니다. 경기 시간은 현지 시간이 아니라 한국 시간으로 바꿔 적었으니 따로 계산할 필요가 없습니다.

{% if sc.key in ('soccer', 'kleague') %}

유럽 리그 경기는 한국 시간으로 보통 저녁 8시부터 다음 날 새벽 5시 사이에 열립니다. 새벽 경기는 날짜가 바뀌므로, {{ kw }}에서 날짜 제목을 함께 확인하세요. 유럽 서머타임이 끝나는 10월 말부터는 같은 현지 시각이라도 한국 시간으로 1시간 늦게 시작합니다.

{% elif sc.key == 'nba' %}

NBA 경기는 미국 현지 저녁 경기가 많아 한국 시간으로는 보통 오전 8시~낮 12시에 시작합니다. 같은 날 여러 경기가 1~2시간 간격으로 이어지므로 {{ kw }}에서 시간 순서대로 확인하면 편합니다.

{% elif sc.key in ('kbl', 'wkbl', 'volleyball') %}

국내 경기는 평일 저녁 7시, 주말 오후 2시·4시 무렵에 많이 열립니다. 일정이 바뀌면 다음 갱신 때 {{ kw }}에도 그대로 반영됩니다.

{% endif %}

각 경기의 확률과 예상 스코어는 해외 배당과 최근 경기 기록으로 계산하고, 화면의 배당은 베트맨 배당입니다. 일정에서 경기를 누르면 마켓별 확률, 두 팀의 최근 흐름, 상대 전적까지 이어서 볼 수 있습니다.
